🎓 Ingesting Kaggle MRI Dataset

Training from scratch requires downloading the Brain Tumor MRI Dataset. The automated setup downloader scripts download files directly from the Kaggle API.

$env:KAGGLE_USERNAME="yourusername"
$env:KAGGLE_KEY="yourkey"
python setup_kaggle_data.py

⚡ Stage-wise Neural Orchestration

The training pipeline executes three dedicated learning phases:

  • Stage 1: EfficientNet-B4 4-class classifier (30 epochs)
  • Stage 2: YOLOv8m spatial bounding box localization (25 epochs)
  • Stage 3: ResNet50-based U-Net pixel segmentation (20 epochs)
